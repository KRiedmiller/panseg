## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature-slug>/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary; each label string is equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root plus `docs/adr/` (neither exists yet). See `docs/agents/domain.md`.

### Conventions

Details on the conda env, use of worktrees, running tests, linting and typechecking and the docs. See `docs/agents/conventions.md`.
